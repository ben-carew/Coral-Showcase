# Ledger — every idea tested on Coral, one row each

**Grep this before proposing anything** (`grep -i <keyword> ledger.md`). One row per
test, newest first within a section. Verdicts: **ADOPTED** (in the code/config),
**VALIDATED** (passes, not yet default), **REJECTED** (made things worse),
**NULL** (no effect), **CLOSED** (question answered, no action), **FIXED** (bug).
The detail lives where the last column points: `arch/` = `archive/2026-09-momentum-campaign/`,
`K§` = a section of `.claude/docs/knowledge.md`, `mem:` = an auto-memory file,
`topics/` = this folder. Add the row in the same edit that records the result.

Other verdict words in use: MEASURED / DONE (a number, no decision), NO-GO / GO / LEAD (a pre-registered step 0),
PASS / FAIL / KILLED (a pre-registered bar), CLOSED = <cause>, NOT RUN, NAMED / NOT NAMED (a mechanism test).

vertex curve not re-derived for it) names or fails to name a lever; it does not reject it. Rejections that rest on a
single 95% interval barely off zero among ~14 are "not decided" (method-traps). Rows amended by the audit carry
